灵墟 · CG 落图目录
================================

把你生成的图，按下面「文件名.jpg」原样放进这个目录（dist-share/assets/cg/），
重新构建（npm run build 或 publish）后自动生效，无需改代码。
图没放也完全没事：页面会自动跳过这张图，绝不破图、不报错。

【统一规格】
  - 横幅图（手机/桌面都按横幅裁切）：建议 1600×900（16:9）或 1500×1000。
  - 格式 jpg，单张 80~200KB 为宜（太大会拖慢加载）。
  - 风格：水墨淡彩 + 暗金点缀，低饱和、电影感、留白多；
    不要加文字、不要加logo；人物可用背影/侧影/剪影，避免正脸大头贴。
  - 色调与现有场景一致（夜色、青灰、一点暖金），不要高饱和卡通。
